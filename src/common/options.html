How to get a free Azure key (5 minutes)
  1. Sign in at portal.azure.com (a free account works).
  2. Search Speech and create a Speech service resource. Pick the Free F0 pricing tier and a region close to you, e.g. Australia East.
  3. Open the resource → Keys and Endpoint. Copy Key 1 and the Location/Region into the boxes above.
  4. Click Load voices below.

Using it

  • Ctrl+Shift+U or the toolbar icon — start / stop reading.
  • Hover a paragraph and click the blue ▶ next to it to read from there. Or Alt+click any sentence.
  • Select text first to start from the selection. Right-click a selection to read only that bit.
  • Alt+Shift+P play/pause · Alt+Shift+←/→ previous/next paragraph · Esc close.
